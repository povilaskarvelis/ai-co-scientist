Use this reference when the objective is comparative.

- Organize the plan around shared evidence dimensions and sources instead of reviewing entity A fully and entity B fully in isolation.
- Apply each evidence step across all compared entities; multiple calls to the same source belong inside that shared step rather than separate entity-specific steps.
- Typical dimensions:
  efficacy or association strength, safety or risk, mechanistic plausibility, selectivity, tractability, biomarker context, trial maturity, and evidence quality.
- If one side has weaker or shallower evidence, make that a comparison finding rather than smoothing it over.
- Capture a requested overall ranking in the success criteria. The downstream report synthesizer performs that comparison, so the evidence plan does not need a synthesis-only step.
